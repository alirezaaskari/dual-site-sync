# بازرسی سواچ‌ها

ابزار مستقل برای پیدا کردن ترم‌هایی که ویژگی‌شان روی **Color** (یا **Image**)
تنظیم شده ولی مقدارشان خالی یا نامعتبر است.

از ماژول `dual-site-sync` کاملاً جداست و به آن وابستگی ندارد.

## استفاده

`swatch-audit.php` را در **ریشه‌ی وردپرس** (کنار `wp-config.php`) بگذارید و
به‌عنوان مدیر در مرورگر باز کنید:

| آدرس | نتیجه |
|---|---|
| `swatch-audit.php` | گزارش کامل، فقط ترم‌های ناقص |
| `swatch-audit.php?only=color` | فقط ویژگی‌های نوع رنگ |
| `swatch-audit.php?only=image` | فقط ویژگی‌های نوع تصویر |
| `swatch-audit.php?all=1` | همه‌ی ترم‌ها، سالم و ناقص |
| `swatch-audit.php?format=text` | خروجی متنی ساده برای کپی کردن |

دسترسی لازم: `manage_woocommerce`. ابزار فقط می‌خواند و هیچ داده‌ای را تغییر
نمی‌دهد.

**پس از استفاده فایل را از سرور پاک کنید.**

## چه چیزی را ناقص می‌شمارد

ویژگی‌های نوع **Color**:

| بررسی | متای ترم |
|---|---|
| کد رنگ خالی | `product_attribute_color` |
| کد رنگ نامعتبر (چیزی جز `#rgb` یا `#rrggbb`) | `product_attribute_color` |
| حالت دو رنگ روشن ولی رنگ دوم خالی یا نامعتبر | `is_dual_color` + `secondary_color` |

ویژگی‌های نوع **Image**:

| بررسی | متای ترم |
|---|---|
| تصویر انتخاب نشده | `product_attribute_image` |
| پیوست انتخاب‌شده دیگر وجود ندارد | `product_attribute_image` |

ویژگی‌های نوع `select`، `button` و `radio` نادیده گرفته می‌شوند، چون رنگ یا
تصویر نمی‌خواهند.

## خروجی

ترم‌های ناقص اول می‌آیند و در هر گروه، پرکاربردترها بالاتر — ستون «محصولات»
تعداد محصولاتی است که ترم به آن‌ها تخصیص داده شده. نام هر ترم لینک مستقیم به
صفحه‌ی ویرایشش است.

کلیدهای متا از افزونه‌ی
[Variation Swatches for WooCommerce](https://wordpress.org/plugins/woo-variation-swatches/)
(رایگان و Pro) گرفته شده‌اند.
